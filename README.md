# 🌱 MicroConnect

### Conectando quem produz a quem consome.

O **MicroConnect** é uma plataforma desenvolvida com o objetivo de aproximar pequenos produtores de seus clientes, promovendo conexões mais acessíveis entre quem oferece produtos e quem procura por eles.

A proposta busca valorizar os pequenos produtores, incentivar o comércio local e explorar como a tecnologia pode facilitar essas conexões.

## 📌 Sobre o projeto

O MicroConnect foi desenvolvido como parte do **Projeto Integrador (PI)** do curso de Desenvolvimento de Software Multiplataforma (DSM), com foco na aplicação prática dos conhecimentos adquiridos ao longo da formação.

A ideia central é criar um ambiente digital que aproxime produtores e consumidores, tornando essa relação mais simples e acessível.

### 🎯 Objetivos

- 🌿 **Valorizar pequenos produtores:** dar visibilidade a quem produz em pequena escala.
- 🤝 **Aproximar pessoas:** facilitar a conexão entre produtores e potenciais clientes.
- 💻 **Utilizar a tecnologia como ponte:** desenvolver uma solução digital para uma necessidade do cotidiano.
- 📚 **Aplicar conhecimentos acadêmicos:** integrar programação, desenvolvimento web e organização de software em um projeto prático.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| C# | Linguagem principal da aplicação |
| ASP.NET Core MVC | Estrutura para o desenvolvimento web |
| .NET 8 | Plataforma de execução do projeto |
| HTML e CSS | Estrutura e estilização das interfaces |

## 🏗️ Estrutura do projeto

A aplicação segue a organização do padrão MVC (*Model-View-Controller*), separando responsabilidades para facilitar a manutenção e a evolução do código.

```text
MicroConnect/
├── Controllers/   # Controle das requisições
├── Models/        # Modelos e representação dos dados
├── Views/         # Interfaces e páginas da aplicação
├── Properties/    # Configurações do projeto
├── wwwroot/       # Arquivos estáticos
├── Program.cs     # Inicialização da aplicação
├── appsettings.json
└── pi.csproj      # Configuração do projeto .NET
```

## ⚙️ Como executar o projeto

### Pré-requisitos

Antes de começar, você precisa ter instalado:

- [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- [Git](https://git-scm.com/)

### 1. Clone o repositório

```bash
git clone https://github.com/guiolizx/MicroConnect.git
```

### 2. Acesse a pasta do projeto

```bash
cd MicroConnect
```

### 3. Restaure as dependências

```bash
dotnet restore
```

### 4. Execute a aplicação

```bash
dotnet run
```

Após iniciar, acesse no navegador o endereço local informado pelo terminal.
